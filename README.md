### Architecture & Implementation Notes
This project was developed with a focus on implementing a custom grid-based architecture and experimenting with various software design patterns. 
While some components have room for refactoring due to rapid prototyping during the hackathon, the codebase reflects practical trials of object-oriented principles, modular system design, and algorithmic grid management without relying on built-in engine abstractions.
